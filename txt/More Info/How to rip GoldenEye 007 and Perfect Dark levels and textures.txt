Requires:
    *   GoldenEye Setup Editor (latest version)
	*	GoldenEye 007/Perfect Dark ROM

===INSTRUCTIONS===
    *   You will have to configure the GoldenEye Setup Editor and obtain the ROMs on your own.
        *   IIRC, the ROMs are not required to be from a specific version of the game, but may need to be byteswapped.
            *   This is a simple process and the GoldenEye setup editor includes tools for doing this (Tools > Trim/Flip ROM Tools).

How to export GoldenEye 007/Perfect Dark levels and textures:
    *   Open the GoldenEye Setup Editor and start a new project (File > New) using the desired level as a base.
        *   You can also choose (Open Setup Uncompressed) to view the level complete with objects.
            *   In the file browser, navigate to [GoldenEye Setup Editor directory]/GE/Setup or [GoldenEye Setup Editor directory]/PD/pdsetup to choose a setup file.
    *   Go to Visual Edit Mode (Edit setup > Visual Editor).
    *   Switch mode to Edit Room Positions Mode (Mode > Switch Mode to > Edit Room Positions Mode).
    *   Right click anywhere in the visual editor window, and click "Export Full Level to .obj".

How to export in-game objects for each level:
    *   Instead of opening a new project, choose (Open Setup Uncompressed) to load a level complete with objects.
    *   Go to Visual Edit Mode (Edit setup > Visual Editor).
    *   In the default mode (Edit Objects Mode), right click in the visual editor window somewhere NOT on an in-game object, and click (Output To Obj > Output Models from Level to .obj).
        *   The Perfect Dark editor does not offer you the option to export all in-game objects; instead you will have to right-click on each and export them individually (), then combine them into a single file.

Notes:
    *   Changing the scale when opening a project in the GoldenEye Setup Editor makes no difference to the output.
